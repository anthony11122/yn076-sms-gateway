# YN076 短信网关 · 烧录与部署指南（v2 串口版）

## 一、准备工作

| 物品 | 说明 |
|---|---|
| Air780EPM Dongle（YN076） | USB 接口，插 SIM 卡（短信卡/保号卡） |
| Windows 电脑 | 装 Luatools v3（官方 docs.openluat.com 下载） |
| Linux 服务器 | 跑 sms_relay.py，需要 USB 口或 PVE 直通 |

固件：LuatOS-SoC V2050（Air780EPM），烧录包 zip 内已含。
新版本可从官方下载：docs.openluat.com → Air780EPM → LuatOS 固件

## 二、烧录（Luatools）

1. Dongle 不插 SIM 也能烧。按住 **BOOT** 键插入 USB → Luatools 识别出下载模式
2. Luatools → 项目管理 → 新建：
   - 脚本文件：`main.lua`（burn-kit zip 内）
   - 底层 CORE：选 zip 内 `LuatOS-SoC_V2050_Air780EPM_106.soc`
   - ✅ 勾选「添加默认 lib」
3. 点「下载底层和脚本」，等待完成
4. 重新上电，Luatools 串口日志看到 `sms_gateway 002.000.000` 即成功

## 三、服务器部署

1. 把 `server/` 下三个文件放到如 `/opt/yn076/`
2. `mkdir -p /var/lib/sms-relay`
3. 启动测试：`python3 sms_relay.py`（默认 8088 端口，纯标准库无依赖）
4. systemd 常驻：`systemctl enable --now sms-relay`（按需改 sms-relay.service 里的路径）

环境变量（可选）：
- `SERVER_PORT`（默认 8088）
- `DB_PATH`（默认 /var/lib/sms-relay/sms.db）
- `BARK_KEY` 等 Bark 变量——**推荐直接在 WebUI 界面配置**（DB 持久化，优先级高于环境变量）

## 四、USB 连接与验证

1. Dongle 插服务器 USB（或 PVE 直通：`qm set <vmid> -usb0 host=19d1:0001`）
2. 服务器出现 `/dev/ttyACM0-2`，其中一个是数据口（脚本自动探测，无需手动指定）
3. 打开 WebUI → 设备状态显示 online（含信号/ICCID）即通
4. 发条短信测试：WebUI 发送框 → 10001 发 `101` → 十几秒后收件箱出现话费回复

## 五、Bark 推送（可选）

WebUI → 「Bark 通知设置」→ 填 Device Key（Bark App 首页）→ 保存 → 测试通知。
支持 AES-128-CBC 端到端加密（WebUI 生成 Key/IV，Bark App 内同步填入）。
新短信自动推送，验证码自动提取到标题和剪贴板。

## ⚠️ 注意

- WebUI 默认无鉴权，只在内网使用；如需公网请自行加反代+认证
- SIM 卡需能收短信（保号套餐即可），流量功能仅"定量消耗保号"用，默认零流量
- ttyACM 设备顺序可能浮动，服务端自动探测（发 ping 握手识别数据口）
